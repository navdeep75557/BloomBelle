```bash

```

### Step 2: Connect to Vercel

- Click "New Project"
- Select your GitHub repository
- Click "Deploy"

### Step 3: Configure Domain (Optional)
- Project Settings → Domains
- Add your custom domain
- Update DNS records

## 🔧 Pre-Deployment Configuration

Before deploying, update these items:

### 1. Google Analytics (Optional)
In `index.html`, line 92:
```html
<script async src="https://www.googletagmanager.com/gtag/js?id=G-YOUR_ID"></script>
```

### 2. Social Links
In `index.html`, footer section:
```html
<a href="https://facebook.com/your-business">Facebook</a>
<a href="https://instagram.com/your-business">Instagram</a>
```

### 3. Contact Information
In `index.html`, JSON-LD section:
```json
"email": "your-email@bloombelle.com",
"telephone": "+1-800-YOUR-FLOWERS"
```

### 4. Domain URLs
Replace `https://bloombelle.vercel.app/` with your actual domain throughout
